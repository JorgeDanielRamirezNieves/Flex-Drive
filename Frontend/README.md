# Librerías instaladas
- Tailwind
- ngprime
- postcss
- @tailwindcss/postcss

# Montar ambiente

## instalar cli de angular
```bash
$ npm install -g @angular/cli
```

## instalar las dependecias del proyecto
```bash
$ npm install 
```

## Angular
Debe de estar instalado un version reciente de Nodejs y npm para manejo de paquetes

### comandos para de la CLI de angular
Para empezar de manera local el proyecto utiliza:
```bash
ng serve
```

Para construir el proyecto
```bash
ng build
```

Para crear un componente
```bash
ng generate|g <schematic> [options]
```
